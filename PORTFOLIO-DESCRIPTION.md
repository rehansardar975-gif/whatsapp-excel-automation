## Your role (64 characters)

## Project description
**Short (for the 300-character limit):**
Upload a contact Excel file and the system cleans it automatically: fixes phone formats, removes duplicates, blocks opted-out and Do Not Contact numbers, then sends one personalised WhatsApp message to every contact and reports what happened. A real n8n workflow runs it end to end.

**Long (for the 600-character limit):**
Many businesses keep contacts in Excel and send WhatsApp messages by hand. I built a system that automates the whole process. Upload an Excel or CSV file and it finds the columns, fixes phone number formats, removes duplicates, and blocks invalid, opted-out and Do Not Contact numbers. One message with {{first_name}} and {{company}} is personalised for every contact and sent through a queue with automatic retries. Results show sent, delivered, failed and skipped, each with a reason, and export to Excel. An n8n workflow runs everything end to end. Built for the official WhatsApp Cloud API.
