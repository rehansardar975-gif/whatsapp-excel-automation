P07 · Architecture

Excel → SheetReach → WhatsApp, orchestrated by n8n

Business rules live in SheetReach. n8n runs the process through SheetReach's API. The WhatsApp provider is swappable: the demo uses a simulated provider, and production uses the official Cloud API.

1

Excel / CSV contact file

Upload in the app, or a new file picked up by n8n (Drive, email, form, CRM export)

2

SheetReach · import & clean

Column detection · phone numbers → +E.164 · duplicates removed · invalid / missing flagged

3

Validation · opt-in · Do Not Contact

Only consented, valid, non-blocked contacts can enter a campaign — re-checked before every send

4

Personalised campaign queue

{{first_name}} · {{company}} · {{city}} per contact · retries with backoff · pause / resume

Used in this demo

Demo WhatsApp provider

Simulated sending and delivery statuses on fictional data. Nothing leaves the app.
Production · client credentials

WhatsApp Business Cloud API

Official Meta API, approved templates. Implemented; switched on with the client's Meta account. Not run against Meta in this demo.
5

Status tracking

Sent · delivered · failed · STOP replies → Do Not Contact (Meta status webhook in production)

6

Results & report

Campaign dashboard with reasons · Excel export · n8n final report

AUTOMATION LAYER

n8n workflow

  • Trigger: manual run or webhook with a file URL
  • Download file → upload to SheetReach
  • Data-quality gate (stops if no phone column)
  • Import clean contacts
  • DNC & opt-in check — stops if nobody is eligible
  • Pick message → create personalised campaign
  • Start sending
  • Poll progress until complete
  • Download Excel results
  • Build final report

Calls the SheetReach REST API with real HTTP Request nodes. It doesn't duplicate any cleaning or sending logic.
